# Panduan Pengguna Sistem JohorUP

## 🎯 Objektif Sistem

Sistem JohorUP adalah platform pemantauan untuk 880 murid Tingkatan 5 yang akan menduduki SPM 2026. Sistem ini membantu:
- Memantau pencapaian murid dalam 3 subjek kritikal (BM, Sejarah, Matematik)
- Merancang dan menguruskan program bimbingan
- Mengurus peruntukan kewangan RM450,000
- Menjana laporan dan analisis

## 👥 Peranan Pengguna

### 1. Sekolah (22 sekolah)
**Akses:**
- Lihat dan kemaskini data murid sekolah sendiri
- Input gred murid untuk setiap peperiksaan
- Lihat program yang melibatkan murid sekolah

**Cara Guna:**
1. Log masuk dengan email sekolah
2. Pergi ke menu "Murid"
3. Klik "Lihat" untuk kemaskini data murid
4. Input gred untuk setiap peperiksaan (Mid-year, Trial, SPM)

### 2. PPD (Pejabat Pendidikan Daerah)
**Akses:**
- Lihat semua sekolah dalam daerah
- Pantau pencapaian murid di daerah
- Input program bimbingan untuk daerah
- Lihat laporan daerah

**Cara Guna:**
1. Log masuk dengan email PPD
2. Dashboard menunjukkan statistik daerah
3. Boleh filter sekolah mengikut daerah
4. Tambah program untuk sekolah dalam daerah

### 3. Sektor Pembelajaran & Pembangunan Murid
**Akses:**
- Lihat semua data negeri
- Rancang program bimbingan
- Urus unjuran kewangan program
- Pantau keberkesanan program

**Cara Guna:**
1. Log masuk dengan email sektor
2. Pergi ke menu "Program"
3. Klik "+ Tambah Program"
4. Isi maklumat program dan anggaran kos
5. Pantau penyertaan murid

### 4. Sektor Perancangan & Pengurusan PPD (Koordinator)
**Akses:**
- Full access ke semua data
- Koordinasi program dan kewangan
- Menjana laporan keseluruhan
- Export data untuk pembentangan

**Cara Guna:**
1. Log masuk dengan email koordinator
2. Dashboard menunjukkan overview keseluruhan
3. Pantau penggunaan bajet di menu "Kewangan"
4. Menjana laporan di menu "Laporan"
5. Export PDF untuk mesyuarat

## 📊 Menu Utama

### Dashboard
- Statistik keseluruhan (murid, sekolah, bajet)
- Kadar kelulusan semasa
- Program aktif
- Peruntukan bajet

### Murid
- Senarai 880 murid
- Data peribadi dan sekolah
- Gred untuk 3 subjek
- Filter dan carian

### Program
- Senarai program bimbingan
- Tambah program baru
- Jadual program
- Peserta program

### Kewangan
- Peruntukan RM450,000
- Bajet mengikut program
- Status perbelanjaan
- Baki peruntukan

### Laporan
- Analisis pencapaian
- Perbandingan sekolah
- Trend pencapaian
- Cadangan tindakan
- Export PDF

## 🔄 Workflow Sistem

### Aliran Kerja Tahunan

**Januari 2026:**
1. Sekolah input data murid dan gred Tingkatan 4
2. Sektor Pembelajaran rancang program
3. Sektor Perancangan luluskan bajet

**Februari - Mac:**
1. Jalankan program intensif
2. Sekolah update kehadiran murid
3. PPD pantau pelaksanaan

**April - Mei:**
1. Sekolah input gred peperiksaan pertengahan tahun
2. Analisis pencapaian
3. Sesuaikan program jika perlu

**Jun - Ogos:**
1. Program tambahan untuk murid lemah
2. Persiapan peperiksaan percubaan
3. Update progress

**September:**
1. Sekolah input gred percubaan
2. Program intensif akhir
3. Motivasi murid

**Oktober - November:**
1. SPM sebenar
2. Pantau kehadiran
3. Support murid

**Disember:**
1. Input keputusan SPM
2. Analisis keberkesanan program
3. Laporan akhir untuk penaja

## 📝 Tips Penggunaan

### Untuk Sekolah:
- Update data murid secara berkala
- Input gred dengan tepat
- Maklumkan jika murid tidak hadir program

### Untuk PPD:
- Pantau sekolah yang perlu bantuan
- Koordinasi program antara sekolah
- Pastikan data dikemaskini

### Untuk Sektor:
- Rancang program berdasarkan data
- Monitor ROI program
- Sesuaikan strategi jika perlu

### Untuk Koordinator:
- Review dashboard setiap minggu
- Menjana laporan bulanan
- Komunikasi dengan penaja

## ❓ Soalan Lazim

**Q: Bagaimana nak reset password?**
A: Hubungi admin sistem atau Sektor Perancangan

**Q: Data murid tidak kelihatan?**
A: Pastikan anda login dengan akaun yang betul. Sekolah hanya boleh lihat murid sendiri.

**Q: Bagaimana nak tambah murid baru?**
A: Hubungi Sektor Perancangan untuk tambah murid ke dalam sistem

**Q: Sistem lambat?**
A: Clear browser cache atau gunakan browser lain (Chrome/Edge recommended)

**Q: Nak export data ke Excel?**
A: Klik butang "Export" di setiap page atau minta admin
