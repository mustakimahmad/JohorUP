## ✅ Cara Lulus Program

```
1. Lihat senarai "Program Menunggu Kelulusan"
2. Semak butiran program
3. Nilai kos dan keperluan
4. Semak baki peruntukan
5. Klik "Lulus" (hijau) atau "Tolak" (merah)
```

## 💸 Cara Turunkan Geran

```
1. Lihat senarai "Program Diluluskan"
2. Klik "Turunkan Geran" (biru)
3. Semak maklumat di modal
4. Pastikan dokumen lengkap
5. Klik "Sahkan Pengeluaran"
```

## 🚦 Kriteria Keputusan

### ✅ LULUS jika:
- Kos munasabah
- Fokus kepada BM/Sejarah/Matematik
- Jadual realistik
- Baki mencukupi
- KPI jelas

### ❌ TOLAK jika:
- Kos terlalu tinggi
- Tidak fokus subjek kritikal
- Jadual tidak realistik
- Baki tidak cukup
- Duplikasi program

## 🎯 Formula Keputusan

```
LULUS = (Keperluan + Kos Munasabah + Baki Cukup) × Impak Murid

TOLAK = Kos Tinggi ∨ Baki Tak Cukup ∨ Tidak Fokus
```

## 💡 Tips Pantas

1. **Proaktif** - Jangan tunggu menimbun
2. **Adil** - Objektif dalam keputusan
3. **Teliti** - Semak setiap butiran
4. **Fleksibel** - Dengar justifikasi
5. **Bertanggungjawab** - Jaga wang penaja
