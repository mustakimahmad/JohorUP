## 📊 Dashboard Anda

### URL: `/dashboard/coordinator`

**Apa yang anda nampak:**

1. **Header**
   - Dashboard Koordinator
   - Sektor Perancangan & Pengurusan PPD
   - Email anda
   - Butang Log Keluar

2. **Navigation Menu**
   - Dashboard (current)
   - Kelulusan Program (coming soon)
   - Pengeluaran Geran (coming soon)
   - Laporan Penuh

3. **5 Kad Statistik**
   - Jumlah Peruntukan (biru)
   - Diluluskan (hijau)
   - Dibelanjakan (ungu)
   - Menunggu Kelulusan (kuning) ⚠️
   - Baki (indigo)

4. **Alert Box** (jika ada pending)
   - Kuning dengan icon warning
   - Bilangan program pending
   - Jumlah RM pending

5. **Table: Program Menunggu Kelulusan**
   - Nama program
   - Penerangan
   - Jumlah (RM)
   - Dikemukakan oleh
   - Tindakan: [Lulus] [Tolak]

6. **Table: Program Diluluskan**
   - Nama program
   - Jumlah (RM)
   - Status badge (hijau)
   - Tarikh lulus
   - Tindakan: [Turunkan Geran]

## 🚀 Quick Start (5 Minit)

### Minit 1: Login
```
1. Buka http://localhost:3000
2. Email: koordinator@jpnj.gov.my
3. Password: demo123
4. Klik "Log Masuk"
```

### Minit 2: Lihat Overview
```
1. Semak 5 kad statistik
2. Perhatikan kad "Menunggu Kelulusan"
3. Baca alert box (jika ada)
```

### Minit 3: Lulus Program
```
1. Scroll ke "Program Menunggu Kelulusan"
2. Baca butiran program pertama
3. Klik "Lulus"
4. Lihat alert confirmation
```

### Minit 4: Turunkan Geran
```
1. Scroll ke "Program Diluluskan"
2. Klik "Turunkan Geran" untuk program pertama
3. Semak maklumat di modal
4. Klik "Sahkan Pengeluaran"
```

### Minit 5: Explore
```
1. Klik "Laporan Penuh" di menu
2. Lihat dashboard utama
3. Explore graf perkembangan murid
4. Kembali ke dashboard koordinator
```

- Jangan lulus tanpa semak baki

- Jangan abaikan alert
