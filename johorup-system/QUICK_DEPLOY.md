# ⚡ Quick Deploy - 5 Minit Sahaja!

## 🎯 Cara Paling Cepat Deploy Demo

### Step 1: Install Vercel CLI (1 minit)

```bash
npm install -g vercel
```

### Step 2: Login (1 minit)

```bash
vercel login
```

Masukkan email anda, check email untuk verify.

### Step 3: Deploy! (3 minit)

```bash
# Di folder johorup-system
cd johorup-system

# Deploy
vercel

# Jawab soalan:
# ? Set up and deploy "johorup-system"? [Y/n] Y
# ? Which scope? [Your account]
# ? Link to existing project? [y/N] N
# ? What's your project's name? johorup-system
# ? In which directory is your code located? ./
# ? Want to override the settings? [y/N] N
```

### Step 4: Done! ✅

```
✅ Deployed to production!
🌐 URL: https://johorup-system.vercel.app
```

---

## 🚀 Deploy Production

Untuk production URL yang permanent:

```bash
vercel --prod
```

---

## 🔄 Update Demo

Bila ada changes:

```bash
vercel --prod
```

Auto update dalam 2-3 minit!
