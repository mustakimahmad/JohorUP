## ✅ Fungsi 1: Meluluskan/Menolak Program

### Senarai Program Menunggu Kelulusan

Anda akan lihat table dengan:
- **Nama Program** - Tajuk program yang dikemukakan
- **Penerangan** - Butiran program
- **Jumlah (RM)** - Anggaran kos
- **Dikemukakan Oleh** - Sektor Pembelajaran/Pembangunan Murid
- **Tindakan** - Butang Lulus/Tolak

### Cara Meluluskan Program:

1. **Semak Butiran Program**
   - Baca tajuk dan penerangan
   - Lihat jumlah permohonan
   - Pastikan ia munasabah

2. **Semak Baki Peruntukan**
   - Lihat kad "Baki" di atas
   - Pastikan peruntukan mencukupi
   - Contoh: Baki RM 100,000, permohonan RM 80,000 = OK

3. **Nilai Keperluan**
   - Adakah program ini diperlukan?
   - Adakah ia akan membantu murid?
   - Adakah kos berpatutan?

4. **Buat Keputusan**
   - Klik butang **"Lulus"** (hijau) - Jika setuju
   - Klik butang **"Tolak"** (merah) - Jika tidak setuju

5. **Hasil**
   - Program yang diluluskan akan hilang dari senarai pending
   - Program akan muncul di senarai "Sedia Untuk Pengeluaran Geran"
   - Alert confirmation akan muncul

### Contoh Keputusan:

**Program 1: Kem Sejarah - RM 80,000**
- ✅ LULUS - Subjek Sejarah perlu perhatian, kos munasabah
- Klik "Lulus"

**Program 2: Tambahan Bahan - RM 50,000**
- ✅ LULUS - Sokongan untuk program sedia ada
- Klik "Lulus"

---

## 💰 Fungsi 2: Menurunkan Geran

### Senarai Program Diluluskan

Selepas anda luluskan program, ia akan muncul di table:
- **Nama Program**
- **Jumlah (RM)**
- **Status:** Diluluskan (badge hijau)
- **Tarikh Lulus**
- **Tindakan:** Butang "Turunkan Geran" (biru)

### Cara Menurunkan Geran:

1. **Pilih Program**
   - Lihat senarai program yang telah diluluskan
   - Pastikan program sudah sedia untuk bermula

2. **Klik "Turunkan Geran"**
   - Modal (popup) akan muncul
   - Paparan maklumat program

3. **Semak Maklumat di Modal**
   ```
   Program: Program Intensif Bahasa Melayu
   Jumlah Geran: RM 120,000
   Penerangan: Bimbingan BM - Gaji tutor, bahan
   
   ⚠️ Pastikan semua dokumen sokongan telah lengkap
   ```

4. **Sahkan Pengeluaran**
   - Jika semua OK, klik **"Sahkan Pengeluaran"**
   - Jika tidak, klik **"Batal"**

5. **Hasil**
   - Alert confirmation akan muncul
   - Geran telah diturunkan
   - Program boleh bermula

### Dokumen Yang Perlu Lengkap:
- ✅ Proposal program
- ✅ Breakdown kos terperinci
- ✅ Surat sokongan PPD
- ✅ Borang permohonan
- ✅ Jadual program

## 📋 Workflow Harian Anda

### Pagi (9:00 AM)
1. Login ke sistem
2. Semak dashboard overview
3. Lihat berapa program pending approval
4. Semak baki peruntukan

### Tengah Hari (11:00 AM - 12:00 PM)
1. Semak setiap program pending
2. Baca penerangan dan justifikasi
3. Buat keputusan lulus/tolak
4. Komunikasi dengan Sektor Pembelajaran jika perlu

### Petang (3:00 PM - 4:00 PM)
1. Turunkan geran untuk program yang diluluskan
2. Pastikan dokumen lengkap
3. Update status dalam sistem
4. Maklumkan kepada pihak berkenaan

### Mingguan (Setiap Jumaat)
1. Review penggunaan bajet
2. Analisis trend permohonan
3. Sediakan laporan ringkas
4. Rancang peruntukan untuk minggu depan

### Bulanan
1. Laporan lengkap kepada pengurusan
2. Analisis keberkesanan program
3. Cadangan penambahbaikan
4. Perancangan untuk bulan depan

## ⚠️ Perkara Yang Perlu Diberi Perhatian

### Red Flags (Tolak Program):
- ❌ Kos terlalu tinggi tanpa justifikasi
- ❌ Program tidak fokus kepada 3 subjek kritikal
- ❌ Jadual tidak realistik
- ❌ Tiada KPI yang jelas
- ❌ Duplikasi dengan program sedia ada

### Green Lights (Lulus Program):
- ✅ Kos munasabah dan terperinci
- ✅ Fokus kepada BM, Sejarah, Matematik
- ✅ Jadual realistik
- ✅ KPI jelas dan boleh diukur
- ✅ Melengkapi program sedia ada

## 💡 Tips Untuk Koordinator Yang Berkesan

### 1. Bersikap Proaktif
- Jangan tunggu permohonan menimbun
- Proses segera untuk elak kelewatan
- Komunikasi awal jika ada masalah

### 2. Bersikap Adil
- Nilai semua permohonan dengan objektif
- Jangan bias kepada sektor tertentu
- Fokus kepada keperluan murid

### 3. Bersikap Teliti
- Semak setiap butiran dengan teliti
- Pastikan dokumen lengkap
- Rekod semua keputusan

### 4. Bersikap Fleksibel
- Dengar justifikasi dari sektor lain
- Buka untuk perbincangan
- Sesuaikan jika perlu

### 5. Bersikap Bertanggungjawab
- Anda penjaga wang penaja
- Setiap keputusan ada impak
- Pastikan wang digunakan dengan bijak

---

## 🚨 Situasi Kecemasan

### Jika Peruntukan Hampir Habis:
1. Freeze semua approval baru
2. Review program yang belum bermula
3. Prioritize program kritikal
4. Maklumkan pengurusan
5. Cari sumber tambahan jika perlu

### Jika Program Gagal:
1. Hentikan pengeluaran geran seterusnya
2. Minta laporan dari pelaksana
3. Nilai punca kegagalan
4. Buat keputusan: teruskan atau hentikan
5. Dokumentasi untuk pembelajaran

### Jika Ada Aduan:
1. Dengar dengan teliti
2. Semak rekod dalam sistem
3. Buat siasatan jika perlu
4. Ambil tindakan pembetulan
5. Maklumkan semua pihak
