📚 Subjects Database Structure

Comprehensive Subject Management System for JohorUP

📖 subjects (Master Mata Pelajaran)
id UUID PK
subject_code VARCHAR(10)
subject_name_bm VARCHAR(255)
subject_name_en VARCHAR(255)
subject_category VARCHAR(50)
subject_type VARCHAR(50)
form_levels TEXT[]
curriculum_standard VARCHAR(50)
paper_count INTEGER
grade_boundaries JSONB
👨‍🏫 subject_teachers (Penugasan Guru)
id UUID PK
teacher_id UUID FK
subject_id UUID FK
school_id UUID FK
form_levels TEXT[]
classes TEXT[]
periods_per_week INTEGER
total_students INTEGER
qualification_level VARCHAR(50)
📊 subject_performance_analytics
id UUID PK
subject_id UUID FK
school_id UUID FK
exam_session_id UUID FK
total_students INTEGER
pass_rate DECIMAL(5,2)
average_marks DECIMAL(5,2)
performance_index DECIMAL(5,2)
📚 subject_resources (Sumber)
id UUID PK
subject_id UUID FK
resource_title VARCHAR(255)
resource_type VARCHAR(50)
author_publisher VARCHAR(255)
form_levels TEXT[]
access_type VARCHAR(20)
usage_rating DECIMAL(3,2)
📋 subject_syllabi (Sukatan Pelajaran)
id UUID PK
subject_id UUID FK
form_level VARCHAR(10)
academic_year INTEGER
syllabus_version VARCHAR(20)
chapters JSONB
learning_standards JSONB
🕐 subject_timetables (Jadual)
id UUID PK
school_id UUID FK
subject_id UUID FK
teacher_id UUID FK
form_level VARCHAR(10)
class_name VARCHAR(50)
day_of_week INTEGER
period_number INTEGER
classroom VARCHAR(50)

🔗 Table Relationships

subjects → subject_teachers One subject can have many teacher assignments
subjects → subject_performance_analytics One subject can have performance data from multiple schools
subjects → subject_resources One subject can have multiple learning resources
schools → subject_timetables Each school has its own subject timetable
users (teachers) → subject_teachers Teachers are assigned to teach specific subjects

🔌 API Endpoints

POST /api/setup-subjects-schema - Setup subjects database schema
POST /api/subjects-management - Comprehensive subjects CRUD operations
GET /api/subjects-management?action=get_subjects - Get all subjects with filtering
GET /api/subjects-management?action=get_subject_teachers - Get teacher assignments
GET /api/subjects-management?action=get_subject_performance - Get performance analytics
GET /api/subjects-management?action=get_timetable - Get subject timetables
