💻 Contoh Query SQL

1. Get All Students with School Info:

SELECT 
  s.id,
  s.ic_number,
  s.name,
  s.class_level,
  s.class_name,
  s.gender,
  s.race,
  sch.name as school_name,
  ppd.name as ppd_name,
  ppd.district
FROM students s
LEFT JOIN schools sch ON s.school_id = sch.id
LEFT JOIN ppd ppd ON sch.ppd_id = ppd.id
ORDER BY s.name;

2. Get Students by School (Role-based Access):

SELECT s.*, sch.name as school_name
FROM students s
LEFT JOIN schools sch ON s.school_id = sch.id
WHERE s.school_id = $user_school_id
ORDER BY s.class_level, s.class_name, s.name;

3. Count Students by Gender and Race:

SELECT 
  gender,
  race,
  COUNT(*) as count
FROM students
GROUP BY gender, race
ORDER BY count DESC;

👥 Role-based Data Access

Super Admin

Access: Semua murid di semua PPD

Scope: Seluruh sistem

PPD User

Access: Murid dalam PPD mereka sahaja

Scope: PPD specific

School Admin

Access: Murid dalam sekolah mereka sahaja

Scope: School specific

Teacher

Access: Murid dalam sekolah + subjek mereka

Scope: School + Subject specific

👤 Personal Info

name: Nama penuh murid

gender: Male/Female

race: Malay/Chinese/Indian/Others

religion: Islam/Buddha/Hindu/Kristian

🏫 Academic Info

class_name: 4 Bestari/4 Cemerlang

📞 Contact Info

parent_phone: No. telefon ibu bapa

created_at: Tarikh rekod dicipta

🔐 Security & Privacy

  • IC Numbers: Sensitive data - access controlled by role
  • Parent Contact: Restricted to school admin and above
  • Address Information: Limited to authorized personnel
  • Audit Trail: All data changes logged automatically
