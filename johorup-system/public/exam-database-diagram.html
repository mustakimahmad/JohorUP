📊 Struktur Database Peperiksaan Murid - Sistem JohorUP

Database structure untuk menguruskan murid yang disasarkan, keputusan peperiksaan, dan perkembangan murid

🔄 Aliran Proses Peperiksaan & Penjejakan

1. IDENTIFY TARGETED STUDENTS
Kenal pasti murid yang perlu disasarkan berdasarkan prestasi baseline
⬇️
2. SET TARGETS & INTERVENTIONS
Tetapkan sasaran gred dan program intervensi (tuition, remedial, enrichment)
⬇️
3. CONDUCT EXAMS
Jalankan peperiksaan (Pertengahan Tahun, Percubaan SPM)
⬇️
4. RECORD RESULTS
Masukkan keputusan peperiksaan dan kira progress automatically
⬇️
5. ANALYZE PROGRESS
Analisis perkembangan dan risk level untuk setiap murid
⬇️
6. INTERVENTION RECOMMENDATIONS
Cadangan program intervensi berdasarkan analisis

🎯 Ciri-Ciri Utama Database

📊 Automatic Progress Calculation

Marks Improvement: current_marks - baseline_marks

Percentage Improvement: ((current - baseline) / baseline) × 100

Progress to Target: ((current - baseline) / (target - baseline)) × 100

🚨 Risk Level Assessment

LOW: Current marks ≥ target marks

MEDIUM: Current marks ≥ 50% of target progress

HIGH: Current marks < 50% of target progress

🎯 Intervention Types

TUITION: Additional classes

REMEDIAL: Catch-up programs

ENRICHMENT: Advanced programs

MENTORING: One-on-one support

📈 Grade Boundaries (SPM)

A+: 90-100 | A: 80-89 | A-: 75-79

B+: 70-74 | B: 65-69

C+: 60-64 | C: 50-59

💻 Contoh Query Analisis

1. Get Targeted Students Progress:

SELECT 
  s.name as student_name,
  ts.subject,
  ts.baseline_marks,
  ts.target_marks,
  pt.current_marks,
  pt.marks_improvement,
  pt.progress_to_target,
  pt.risk_level
FROM targeted_students ts
JOIN students s ON ts.student_id = s.id
LEFT JOIN student_progress_tracking pt ON ts.id = pt.targeted_student_id
WHERE ts.status = 'ACTIVE'
ORDER BY pt.risk_level DESC;

2. Intervention Recommendations:

SELECT 
  s.name,
  ts.subject,
  pt.risk_level,
  CASE 
    WHEN pt.risk_level = 'HIGH' THEN 'Intensive remedial required'
    WHEN pt.risk_level = 'MEDIUM' THEN 'Regular monitoring needed'
    ELSE 'Continue current approach'
  END as recommendation
FROM targeted_students ts
JOIN students s ON ts.student_id = s.id
LEFT JOIN student_progress_tracking pt ON ts.id = pt.targeted_student_id
WHERE pt.risk_level IN ('HIGH', 'MEDIUM');

🔐 Security & Role-Based Access

  • Super Admin: All exam data and progress tracking
  • PPD User: Schools within their PPD only
  • SISC+: Subject-specific data within their PPD
  • School Admin: Their school's students only
  • Teacher: Assigned students and subjects only
